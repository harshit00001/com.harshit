# Spring Bean Learning Guide

This folder contains comprehensive examples explaining Spring Beans for interviews.

## What is a Spring Bean?
A Spring Bean is an object that is instantiated, assembled, and managed by the Spring IoC (Inversion of Control) container. 
Beans are the backbone of a Spring application.

## Topics Covered:
1. **Bean Creation Methods** - Different ways to create beans
2. **Bean Scopes** - Singleton, Prototype, Request, Session, etc.
3. **Bean Configuration** - Using @Configuration and @Bean
4. **Component Scanning** - @Component, @Service, @Repository, @Controller
5. **Bean Lifecycle** - Initialization and Destruction callbacks
6. **Dependency Injection** - Constructor, Setter, Field injection

## File Structure:
- `basic/` - Basic bean creation examples
- `scopes/` - Different bean scopes
- `lifecycle/` - Bean lifecycle hooks
- `configuration/` - Configuration classes
- `demo/` - Main demo application
