# Hibernate SQL Logging and Dialect Guide

## 🔍 How to See Hibernate SQL Queries

### Method 1: Console Output (Already Enabled)

SQL queries are automatically logged to the console. You'll see:

```
Hibernate: 
    select
        user0_.id as id1_0_,
        user0_.age as age2_0_,
        user0_.email as email3_0_,
        user0_.name as name4_0_
    from
        users user0_
    where
        user0_.id=?
```

**Configuration in application.properties:**
```properties
spring.jpa.show-sql=true
spring.jpa.properties.hibernate.format_sql=true
logging.level.org.hibernate.SQL=DEBUG
logging.level.org.hibernate.type.descriptor.sql.BasicBinder=TRACE
```

---

### Method 2: H2 Console (Run SQL Directly)

**URL:** `http://localhost:8080/h2-console`

**Login:**
- JDBC URL: `jdbc:h2:mem:testdb`
- Username: `sa`
- Password: (empty)

**Run SQL queries:**
```sql
-- See all users
SELECT * FROM users;

-- See table structure
DESC users;

-- Count records
SELECT COUNT(*) FROM users;
```

---

### Method 3: API Endpoint (Hibernate Info)

**URL:** `GET http://localhost:8080/api/hibernate/info`

**Response shows:**
- Hibernate Dialect: `org.hibernate.dialect.H2Dialect`
- Database Name: H2 Database
- Hibernate Version
- SQL Logging Status
- Connection Details

**Example:**
```bash
curl http://localhost:8080/api/hibernate/info
```

---

### Method 4: Actuator Endpoints

**URL:** `http://localhost:8080/actuator/env`

Shows all environment properties including Hibernate configuration.

## 📊 Hibernate Dialect Information

### Current Configuration

| Property | Value |
|----------|-------|
| **Dialect** | `org.hibernate.dialect.H2Dialect` |
| **Database** | H2 (In-Memory) |
| **SQL Logging** | Enabled |
| **Format SQL** | Enabled |
| **Show Comments** | Enabled |

### Dialect Location

The dialect is configured in `application.properties`:
```properties
spring.jpa.database-platform=org.hibernate.dialect.H2Dialect
```

## 📝 SQL Query Examples

### Generated by Hibernate:

**Find by ID:**
```sql
SELECT u.id, u.name, u.email, u.age 
FROM users u 
WHERE u.id = ?
```

**Pagination:**
```sql
SELECT u.id, u.name, u.email, u.age 
FROM users u 
ORDER BY u.id ASC 
LIMIT ? OFFSET ?
```

**Count:**
```sql
SELECT COUNT(u.id) 
FROM users u
```

## 🔧 Logging Levels

### Current Configuration:
```properties
# Show SQL queries
logging.level.org.hibernate.SQL=DEBUG

# Show parameter values
logging.level.org.hibernate.type.descriptor.sql.BasicBinder=TRACE

# Show JPA queries
logging.level.org.springframework.orm.jpa=DEBUG
```

### What Each Level Shows:

- **DEBUG (org.hibernate.SQL)**: Shows SQL queries
- **TRACE (BasicBinder)**: Shows parameter values
- **DEBUG (org.springframework.orm.jpa)**: Shows JPA operations
