# React 7 Days Interview Learning - Practical Project

A comprehensive 7-day React learning program with practical examples, detailed explanations, and interview preparation materials.

## 📚 Project Overview

This project is designed to help you master React in 7 days through hands-on practice. Each day focuses on specific React concepts with:
- **Simple explanations** for beginners
- **Technical explanations** for deeper understanding
- **Code examples** with detailed comments
- **Interview questions** and answers
- **Step-by-step execution guides**

---

## 🗓️ 7 Days Curriculum

### Day 1: React Basics
- Components (Functional & Class)
- JSX Syntax
- Props and Default Props
- Component Composition

### Day 2: State Management
- useState Hook
- useEffect Hook
- State vs Props
- Component Lifecycle

### Day 3: Event Handling & Forms
- Event Handlers
- Controlled Components
- Form Validation
- Input Handling

### Day 4: Lists & Conditional Rendering
- Rendering Lists
- Keys in Lists
- Conditional Rendering
- map(), filter(), reduce()

### Day 5: Advanced Hooks
- Custom Hooks
- useContext
- useReducer
- useMemo & useCallback

### Day 6: Routing & Navigation
- React Router
- Navigation
- Route Parameters
- Protected Routes

### Day 7: API Integration & Advanced Patterns
- Fetch API / Axios
- Async/Await
- Error Handling
- Loading States
- Advanced Patterns

## 🚀 Quick Start

### Prerequisites

- **Node.js** (v16 or higher)
- **npm** or **yarn**
- Basic knowledge of JavaScript and HTML

### Installation

1. **Navigate to project directory:**
```bash
cd "C:\Java code\com.harshit\react-7days-interview"
```

2. **Install dependencies:**
```bash
npm install
```

3. **Start development server:**
```bash
npm run dev
```

4. **Open browser:**
Navigate to `http://localhost:3000`

## 📖 How to Use This Project

### For Each Day:

1. **Read the README:**
   - Navigate to the day's folder (e.g., `day1/`)
   - Read `README.md` for concepts and explanations

2. **Study the Examples:**
   - Each example file has detailed comments
   - Simple explanations for beginners
   - Technical explanations for deeper understanding

3. **Run the Examples:**
   - Import examples in your `App.jsx`
   - See them in action in the browser
   - Experiment and modify the code

4. **Practice:**
   - Complete the practice exercises
   - Try building similar components
   - Review interview questions

## 🐛 Troubleshooting

### Port Already in Use
```bash
# Change port in vite.config.js
server: {
  port: 3001  // Use different port
}
```

### Module Not Found
```bash
# Reinstall dependencies
rm -rf node_modules
npm install
```

### Build Errors
```bash
# Clear cache and rebuild
npm run build -- --force
```
