## 📖 Simple Explanation

### React Router

**Simple:** React Router lets you create different "pages" in your app. When you click a link, it shows a different component without refreshing the page.

**Technical:** React Router is a library for routing in React applications. It enables client-side routing, allowing navigation without page reloads.

### Routes

**Simple:** Routes are like different pages in your app. Each route shows a different component when you visit that URL.

**Technical:** Routes map URLs to components. React Router matches the current URL and renders the corresponding component.

## 🎓 Interview Answers

### Q1: What is React Router?

**Simple Answer:**
React Router is a library that lets you create different pages in your React app. It handles navigation without refreshing the page.

**Technical Answer:**
React Router is a routing library for React that enables client-side routing. It uses the browser's history API to update the URL and render different components.
