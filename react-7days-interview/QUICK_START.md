# Quick Start Guide - React 7 Days Interview Learning

## 🚀 Fastest Way to Get Started

### Step 1: Install Dependencies

```bash
cd "C:\Java code\com.harshit\react-7days-interview"
npm install
```

### Step 2: Start Development Server

```bash
npm run dev
```

### Step 3: Open Browser

Navigate to: `http://localhost:3000`

---

## 📚 How to Study Each Day

### For Each Day:

1. **Read the README:**
   ```
   Open: day1/README.md (or day2, day3, etc.)
   ```

2. **Study Examples:**
   ```
   Open example files in the day folder
   Read both simple and technical explanations
   ```

3. **Run Examples:**
   ```jsx
   // In src/App.jsx, import and use:
   import Example1 from './day1/Example1-BasicComponent';
   
   function App() {
     return <Example1 />;
   }
   ```

4. **Practice:**
   - Complete exercises in README
   - Modify examples
   - Build your own components
