## 📚 Topics Covered

### Basics
- ✅ Dependency Injection (4 types)
- ✅ Constructor vs Setter Injection
- ✅ Bean Creation (@Component vs @Bean)
- ✅ @Component, @Service, @Repository
- ✅ @Async annotation
- ✅ @Controller vs @RestController
- ✅ Request Mapping
- ✅ Exception Handling
- ✅ @Value annotation

### Advanced
- ✅ WebClient vs RestTemplate
- ✅ Spring MVC Request Flow
- ✅ AOP (Aspect-Oriented Programming)
- ✅ Batch Processing
- ✅ Multiple Database Configuration
- ✅ Exception Handling & Resilience Patterns

### JPA
- ✅ @Id and @GeneratedValue
- ✅ FetchType.LAZY vs EAGER
- ✅ @Transient annotation
- ✅ @ElementCollection
- ✅ Cascade Operations
- ✅ Spring Data JPA

## 🎯 How to Use This Project

1. **Read the README.md** - Contains all questions and answers in a natural, speakable format
2. **Study the Code Examples** - Each Java file contains detailed comments explaining concepts
3. **Practice Speaking** - Read the README answers out loud to practice for interviews
4. **Run the Code** - Execute examples to see concepts in action

## 💡 Interview Tips

- **Practice Speaking**: Read the README answers out loud multiple times
